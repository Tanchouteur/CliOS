# Support

- Questions and setup help: GitHub Discussions.
- Reproducible bugs: use the bug issue form and attach a reviewed diagnostic bundle when useful.
- Vehicle profiles and themes: use their dedicated proposal forms.
- Security: use GitHub Private Vulnerability Reporting only; see [SECURITY.md](SECURITY.md).

Supported deployment is Raspberry Pi 5, Raspberry Pi OS Bookworm/Trixie 64-bit, and 1920×720. Raspberry Pi 4 is experimental. macOS, Windows, and x86 are development/mock environments. CliOS is an accessory display and cannot replace required certified instruments.
