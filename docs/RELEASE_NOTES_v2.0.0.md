# CliOS 2.0.0

CliOS 2.0 unifie les cinq thèmes derrière AppShell et Theme API v1, publie les schémas communautaires v1, sépare releases et données, et remplace la mise à jour Git en production par un staging SHA-256 avec activation atomique et rollback N-1.

Official target: Raspberry Pi OS Bookworm 64-bit, Raspberry Pi 4/5, 1920×720. Theme API v1 and data schemas v1 remain compatible throughout 2.x.
