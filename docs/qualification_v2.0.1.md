# Qualification matérielle v2.0.1

Ce document est la fiche de preuve à compléter avant de créer le tag stable.

## Raspberry Pi 5 — obligatoire

- [ ] installation propre Raspberry Pi OS Bookworm 64 bits ;
- [ ] rendu et tactile en 1920×720 ;
- [ ] réception et diagnostic sur interface CAN réelle ;
- [ ] mise à jour depuis une installation v2.0.0 ;
- [ ] stockage USB, stockage interne et OverlayFS/RAM ;
- [ ] staging d'une archive interrompue puis reprise manuelle ;
- [ ] activation avec marqueur de santé ;
- [ ] absence de marqueur et rollback automatique N-1 ;
- [ ] retour direct du canal bêta vers la dernière stable ;
- [ ] bundle diagnostic contenant manifeste et erreur updater.

Noter pour chaque ligne la date, l'image système, le matériel CAN, le résultat
et le lien vers les journaux. Aucun tag stable ne doit être créé tant qu'une
ligne obligatoire reste ouverte.
