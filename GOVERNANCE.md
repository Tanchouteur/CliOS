# Governance

CliOS currently follows a maintainer-led model. Louis (`@Tanchouteur`) is the lead maintainer and has final responsibility for technical direction, security response, merges, and releases.

Contributors influence the project through issues, pull requests, testing, and documented design discussion. Decisions favor user safety, backward-compatible community contracts, maintainability, and evidence from supported hardware. When consensus is not possible, the lead maintainer records the decision and rationale.

This lightweight model can be revisited when sustained contributor activity makes shared maintenance useful. CliOS does not currently require votes or a formal RFC process.
